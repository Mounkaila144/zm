2. `MockRecognizer` retourne des transcriptions déterministes configurables pour les tests.
3. Le service ASR est isolé de l'API (paquet/module séparé), sélectionnable par configuration.
4. Des tests valident le contrat de l'interface et le comportement du Mock.

### Contrat de l'interface `SpeechRecognizer`

```python
# services/api/app/asr/base.py
from typing import Protocol, List
from pydantic import BaseModel

class AudioInput(BaseModel):
    """Audio PCM16 mono 16kHz en mémoire (bytes) ou chemin fichier."""
    data: bytes
    format: str = "wav"   # pour extensibilité

class Candidate(BaseModel):
    """Candidat alternatif de reconnaissance."""
    number: int | None    # None si non numérique
    text: str
    score: float

class AsrResult(BaseModel):
    """Résultat brut de reconnaissance (avant normalisation)."""
    text: str                    # transcription ASR brute
    acoustic_score: float        # 0-1, confiance du modèle
    candidates: List[Candidate] = []  # alternatives (CTC/LLM)
    latency_ms: int              # latence ASR uniquement
    model_version: str           # ex: "mock-1.0.0", "omniASR_CTC_300M_v2"

class SpeechRecognizer(Protocol):
    """Contrat abstrait pour reconnaissance vocale — remplaçable (NFR9)."""
    def transcribe(self, audio: AudioInput) -> AsrResult: ...
    @property
    def model_version(self) -> str: ...
```
[Source: architecture.md#Components — SpeechRecognizer] [Source: architecture.md#API Specification — RecognitionResponse]

- `AudioInput.data` contiendra les bytes audio décodés validés (MIME, taille, conversion 16kHz — voir story 2.4). En 2.2, on définit seulement la structure ; les tests passeront des bytes dummy. [Source: architecture.md#Backend Architecture — Controller Template]
- `Candidate.number` est `int | None` (parsed) pour anticipation : l'ASR réel ne connaît pas les nombres, seulement du texte. Le parsing arrive après dans le pipeline API (story 2.3). [Source: architecture.md#Core Workflows — Reconnaissance]

### Implémentation `MockRecognizer`

```python
# services/api/app/asr/mock.py
from .base import SpeechRecognizer, AsrResult, AudioInput, Candidate

class MockRecognizer:
    """Implémentation déterministe pour tests/dev — sans GPU ni dépendance externe."""
    def __init__(self) -> None:
        self._text = ""      # texte configurable via set_text()
        self._acoustic_score = 1.0
    
    def set_text(self, text: str, acoustic_score: float = 1.0) -> None:
        """Configure la transcription retournée par transcribe() — déterministe pour tests."""
        self._text = text
        self._acoustic_score = acoustic_score
    
    def transcribe(self, audio: AudioInput) -> AsrResult:
        """Retourne un résultat configuré — candidates vide (pas de modèle réel)."""
        return AsrResult(
            text=self._text,
            acoustic_score=self._acoustic_score,
            candidates=[],
            latency_ms=50,  # simulé
            model_version=self.model_version
        )
    
    @property
    def model_version(self) -> str:
        return "mock-1.0.0"
```
[Source: architecture.md#Components — SpeechRecognizer] [Source: architecture.md#Coding Standards]

- **Aucune dépendance externe** (ni httpx, ni PyTorch) — zéro GPU, purement algorithmique pour tests. [Source: architecture.md#Components — SpeechRecognizer]
- `candidates` vide car pas de modèle réel — les implémentations Remote (Epic 5) le rempliront. [Source: architecture.md#Components — SpeechRecognizer]

- **Isolation complète** : le module `asr/` est découplé de `zarma_numbers` et de FastAPI — seulement les modèles Pydantic partagés. [Source: architecture.md#Coding Standards — "Isolation du moteur linguistique"]
