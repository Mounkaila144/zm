### Contexte général

### Pipeline CI de référence (`.github/workflows/ci.yaml`)

```yaml
name: ci
on: [push, pull_request]
jobs:
  backend:
    runs-on: ubuntu-latest          # aucun GPU
    steps:
      - uses: actions/checkout@v4
      - uses: astral-sh/setup-uv@v3
      - run: uv sync
      - run: uv run ruff check .
      - run: uv run pytest packages/zarma_numbers   # (services/api ajouté dans Epic 2)
  # mobile: (job Flutter ajouté quand apps/mobile aura du code — Epic 3)
```

En story 1.1, le job `backend` doit au minimum exécuter **lint + tests de `zarma_numbers`** (AC4). Le job invariant exhaustif et le job `mobile` s'ajouteront avec leurs stories/epics respectifs. [Source: architecture.md#CI/CD Pipeline]
